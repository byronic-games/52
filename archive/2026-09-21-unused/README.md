# Archived unused files

These files were moved out of the active project tree on 2026-09-21. Nothing was deleted.

## Contents

- `source-card-bundle/` - original `Casino/` import; its LargeCards and SmallCards are byte-for-byte duplicates of the integrated files under `images/`. Chips and dice are not currently referenced.
- `source-card-bundle.zip` - original compressed card-asset bundle.
- `loose-images/` - unreferenced image experiments from the active `images/` root.
- `legacy-face-card-archive/` - the archive that was previously nested under `images/face_cards/`.
- `prototype-workspace/` - obsolete workspace pointing at the older `Mobileversion_GIT/proto2203xyz-MobileUI` project.
- `stitch-prototype/` and `stitch-prototype.zip` - unreferenced design prototype sources formerly under `tools/`.

The active `images/face_cards/` directory remains in place because the renderer still uses it as a fallback if full-card artwork is unavailable.
